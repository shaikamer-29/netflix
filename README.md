📊 Netflix Data Analysis (SQL + Excel + PowerBI)
🔹 Project Overview
Analyzed the Netflix dataset to uncover insights on movies, TV shows, genres, release trends, and country distributions. Combined SQL queries, Excel cleaning & pivot tables, and PowerBI dashboards for a complete end‑to‑end analysis workflow.

🔹 Tools & Technologies
SQL → Querying & aggregation

Excel → Data cleaning

PowerBI → Interactive visualizations

🔹 Process
Data Cleaning (Excel)

Removed duplicates, standardized values, formatted release years.

Built pivot tables for type, genre, and country.

SQL Analysis

Counted total titles.

Compared movies vs TV shows.

Identified top genres.

Tracked yearly release trends.

Mapped country‑wise distribution.

PowerBI Dashboards

Bar chart: Movies vs TV Shows

Line chart: Releases per year

Pie chart: Country distribution

Treemap: Seasons across countries

🔹 Key Findings
Netflix has more movies than TV shows.

USA & India dominate content production.

Drama & Comedy are the most frequent genres.

Releases have sharply increased in recent years.

Strong partnerships visible with recurring directors/actors.

🔹 Conclusion
This project demonstrates data cleaning, SQL querying, and visualization skills applied to a real dataset. It highlights how structured analysis can reveal business insights and guide strategic decisions.
